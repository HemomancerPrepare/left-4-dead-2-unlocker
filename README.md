# Left 4 Dead 2 unlocker

Left 4 Dead 2 unlocker for Windows. The overlay runs next to the game, reads a local config, and does not replace the official client.

## Features

- External overlay for Left 4 Dead 2
- Menu opens on Home
- Config file next to Left4Dead2.exe
- Windowed and borderless layouts
- Runs outside the game process

## Build

1. Open the solution in Visual Studio 2022, x64.
2. Build Release.
3. Start Left 4 Dead 2, then run `Left4Dead2.exe`.
4. Press Home to open the menu.

## Requirements
